# Replacement evidence and context length after deletion

Frozen deletion had lower mean effect error than fixed-ranking repacking on all four completed development studies. That comparison changed the evidence and the length of the resulting context. This follow-up separates those changes along a specified path at the same 512-token cap and on the same fixed answer targets.

1. Start with frozen deletion. Drop any surviving factual chunks that fixed-ranking repacking would evict. This gives the shared chunks in a physically compact prompt.
2. Embed those same chunks in the repacked prompt and mask all replacement keys in every layer. First assign the visible tokens their compact position IDs. Compare against the physically compact score to check the change in tensor shape.
3. Keep the same mask, tokens and tensor shape. Use expanded position IDs so the surviving evidence, question and answer take their repacked positions. This contrast measures the effect of position expansion with the visible evidence held fixed.
4. Make the replacement slots visible. This keeps tensor shape and positions fixed, while changing both attended length and evidence.
5. Compare the actual replacement text with donor text in exactly the same slots. Both versions attend to the same number of tokens at the same positions. Donors come from other development questions in sorted ID order and exclude titles present in the question's source set. This contrast depends on that donor choice, and title exclusion alone cannot guarantee semantic irrelevance.

The sequential differences sum to the frozen-to-repacked change. They depend on the chosen sequence of interventions. In particular, the experiment distinguishes position IDs, changes in visible token count, and replacement identity relative to this donor control. It does not establish a unique decomposition across all possible interventions.

Use 24 questions per study selected by the SHA256 order of `replacement-layout-v1:` plus the question ID before inspecting new outcomes. Use the first 24 for Hotpot and eight per hop stratum for MuSiQue. Run both Qwen7 and Llama8 on the same benchmark-specific IDs. Validate the dataset and reference trace, exact factual memory, factual scores and fully visible repack scores. Use the archived FP32 math attention contract and explicit four-dimensional masks. Check that changing masked token IDs has no effect above 1e-7 on one replacement branch per applicable question. Record the maximum physically compact versus dense compact-position score difference. The smoke must pass 1e-4 on both benchmarks and both model families. A full-study excess above that tolerance blocks the direction rule, and its discrepancy remains visible in the report.

Report every arm and paired MAE contrast with question bootstrap intervals. Flag evictions and the numerical shape residual separately. The automatic review favors attended replacement slots if activation increases MAE and exceeds the position contribution in at least one study on each benchmark, with no study supporting the opposite direction. It attributes the increase specifically to replacement identity only when actual replacements also do worse than equal-length donors on both benchmarks with no opposite result. The analogous positional rule requires a positive position contribution that exceeds activation on both benchmarks with no opposite result. Otherwise retain the broader selection-contract finding. These are exploratory unadjusted intervals on shared development questions. The rule is a paper-direction aid.
