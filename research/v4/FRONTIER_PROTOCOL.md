# FP32 budget and selection study, specified before outcomes

Development only. The three-seed paired method failed its advancement gate, the stronger generated-summary controls completed with substantial raw-influence error, and the selected CUDA positional equivalence gate failed at 0.0001. These outcomes motivate a narrower question: how do actual memory allowance and post-deletion selection affect raw-reference transfer? This is exploratory, not a frozen confirmatory hypothesis or a positional mechanism claim.

Use all 96 development questions on each benchmark (Hotpot, MuSiQue), with Qwen2.5-7B and Llama3.1-8B answerers. No additional training, model downloads or test access. Four array jobs, one GPU at a time, at most 45 minutes each, after a five-minute two-question-per-benchmark Qwen smoke. Include the 7,489 actual GPU seconds already used in this stage: adding full new limits gives 18,589 seconds, below the existing six-hour/21,600-second cap. Mistral replication is not included in this reservation.

For each question, generate a fresh FP32 raw-context greedy answer (64-token cap, repetition penalty one); hold its exact token span fixed across methods and singleton deletions. Model weights are upcast from the existing frozen weights. Force math attention, disable TF32, use explicit 4D boolean causal masks for likelihoods and double-precision log-softmax. Generation uses an explicit all-ones 2D attention mask. This defines a new answering/scoring distribution; it is not a bitwise replication of prior BF16 outcomes or certification of gapped-position equivalence. All deletion constructions use ordinary compact positions.

Methods: raw passthrough; global BM25-style extraction at caps 128, 256, 512, 1024; and a frozen-selection 512 control. At 512, both variants have **identical factual tokens and answer**, checked through token hashes. Recomputed selection refits context IDF and repacks remaining sources after deletion. Frozen selection removes only selected chunks belonging to the deleted source and never refills. Neither is uniquely correct: these are different executable intervention contracts. Their difference isolates selection-policy changes conditional on the same factual memory; it does not isolate layout, distinguish IDF refitting from refill, or represent a novel attribution method. Store source ownership and achieved factual/intervened lengths. Verify the provenance-aware selector exactly matches the frozen lexical implementation on every factual and recomputed branch.

Validate repeated same-shape raw scoring to 1e-7 and re-execute the passthrough endpoint for all singleton deletions, requiring agreement to 1e-7. Failure aborts; incomplete/time-limited studies remain explicitly incomplete. The smoke exercises both benchmarks, selector identity, repeatability, endpoint, all budgets and the frozen-selection branch. Old numerical gates are unchanged.

Primary summaries: QA F1, achieved positions, mean per-question source-effect MAE and pooled NMAE, zero-effect NMAE=1, and top-source rank recovery. Report all four budgets without assuming monotonicity. Main paired contrasts are 1024-minus-128 effect MAE and frozen-minus-recomputed at 512; show question-bootstrap intervals with fixed seed 20261108 and 5,000 resamples, without treating source deletions or seeds as independent questions. These are adaptive exploratory intervals, unadjusted for multiple comparisons.

Report same-normalized-factual-answer and both-correct slices as post-outcome diagnostics, including their sample counts. Fixed selection at 512 controls factual QA by construction, but different post-deletion lengths are part of the compared intervention contract, not a matched-intervention-budget claim. A high error at all budgets supports a transfer limitation only for these implementations/distributions. A successful raw endpoint is an implementation check, not scientific evidence that raw memory solves attribution. Released compression methods and a later locked confirmation remain necessary for broad paper claims.
